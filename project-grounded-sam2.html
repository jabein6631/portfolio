◆ About the Project

AI-Agent / Grounded SAM 2 is an advanced computer vision system that enables open-world object detection, segmentation and tracking using state-of-the-art foundation models.

It accepts arbitrary natural language text prompts (e.g. "person, car, dog") and performs zero-shot object detection using Grounding DINO, generates pixel-accurate masks with SAM 2, and tracks objects across video frames with persistent tracking IDs.

The system supports both high-resolution static images and custom videos, high-resolution inference using SAHI (Slicing Aided Hyper Inference), and exports all results as structured JSON.

◆ Technical Workflow Overview

Step Process Technical Description
01 Prompt Input User supplies input frame/video alongside arbitrary natural-language query strings.
02 Object Detection Grounding DINO parses prompt and extracts high-probability bounding boxes with logits.
03 Box Filtering Applies Box Threshold and Text Threshold filters to remove low-confidence detections.
04 Segmentation Passes filtered bounding boxes into SAM 2 to synthesize binary pixel-accurate mask maps.
05 Video Tracking SAM 2 Video Predictor encodes memory attention to track segmented objects through video frames.
06 Visualization Renders bounding boxes, translucent mask colors, and persistent ID labels using Supervision.
07 JSON Export Dumps coordinates, confidence scores, tracking IDs, and polygon coordinates to JSON.

◆ Technical Challenges & Learnings

  • GPU memory optimization: Balancing SAM 2 video memory attention banks during long video inference.
  • ID persistence through occlusion: Preventing ID switches when detected pedestrians cross paths.
  • Cross-model latency: Pipelining Grounding DINO detections into SAM 2 mask predictors efficiently.
