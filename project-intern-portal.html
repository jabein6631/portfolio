◆ About the Project

Intern Portal is a full-stack web application designed to manage internship programs efficiently. It provides tools for task management, attendance tracking, daily journals, analytics, calendar management, and mentor communication.

The platform helps organizations and mentors monitor intern progress while giving interns a clean and organized workspace to stay on track with their tasks and submissions.

◆ Key Features

  • Secure authentication with JWT & bcrypt
  • Task creation, assignment & status tracking
  • Submission management and file attachments
  • Attendance check-in, checkout & telemetry
  • Daily journals & mentor review comments
  • Groq AI assistant for automated task evaluations
  • Calendar & upcoming event management
  • Mentor chat & peer-to-peer messaging
  • Analytics & performance dashboard with Recharts
  • Role-based access control (Intern, Mentor, Admin)
  • User profile configuration & account settings
  • Responsive Next.js & Tailwind CSS interface

◆ Verified Tech Stack

FRONTEND

  • Recharts: Interactive SVG charting for telemetry & attendance

BACKEND & AI

  • Python 3 & Flask 3: Modular micro-framework with Blueprint routing
  • MongoDB & PyMongo: High-performance multi-database document store
  • PyJWT & bcrypt: Stateless JSON Web Token authentication & hashing
  • Groq AI Engine: Ultra-fast LLM inference for evaluations & summaries
  • Gunicorn: Production WSGI HTTP server

◆ Backend REST API Architecture

Method Endpoint Module & Purpose Action
POST /auth/login Authenticates user credentials and returns signed JWT token.
POST /auth/register Registers new intern or mentor profile with bcrypt password hashing.
GET /intern/tasks/?userId= Retrieves all assigned tasks with status, deadlines, and priorities.
POST /intern/tasks/ Creates and assigns an internship task to intern profiles.
PATCH /intern/tasks/:id/status Updates task lifecycle status (In Progress, Review, Completed).
POST /intern/attendance/checkin Records attendance timestamp and starts daily session timer.
GET /intern/journals/?userId= Retrieves daily progress journal records and mentor feedback.
POST /ai/evaluate Groq AI evaluation pipeline assessing submission completeness.

◆ What I Built (Engineering Contributions)

Frontend & Architecture:

  • Designed comprehensive dashboard UI with dark glassmorphic styling.
  • Implemented interactive Recharts graphs for weekly attendance tracking.
  • Built task lifecycle state machine (In Progress, Review, Completed).

Backend & Database:

  • Engineered modular Flask Blueprint architecture separating intern & mentor scopes.
  • Configured role-based JWT verification middleware for route protection.
  • Integrated Groq AI for automated submission quality evaluation.

Technical Challenges

  • Cross-origin authentication: Coordinating JWT cookies and headers across Next.js on Vercel and Flask backend.
  • State complexity: Managing synchronized updates across tasks, daily attendance timers, and messaging without layout shifts.
  • Multi-tenant schema design: Structuring MongoDB collections across Intern, Mentor, and Institution scopes.

Key Learnings

  • Architecting enterprise SaaS workflows bridging Next.js frontend with Python microservices.
  • Developing scalable MongoDB schemas using PyMongo for document tracking.
  • Applying Groq AI acceleration to generate immediate feedback on student submissions.
