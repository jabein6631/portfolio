◆ About the Project

AI Fitness Maker is a full-stack fitness application designed to provide personalized workout and meal recommendations while using computer vision to analyze exercise movement in real time.

Built from the ground up to address the disconnect between static workout plans and real-time exercise execution, the application unifies user biometric profiling, BMI computation, goal selection, AI pose estimation, workout session tracking, and persistent session history into a single cohesive engineering workflow.

The Problem

Traditional fitness applications often rely on manual workout tracking and generic recommendations:

  • Users struggle with choosing suitable workouts for their body.
  • Lack of guidance on adhering to structured nutritional plans.
  • Manual rep tracking is tedious, distracting, and inaccurate.
  • No real-time feedback to detect improper form or posture errors.

The Solution

AI Fitness Maker combines personalized recommendations, workout tracking, and MediaPipe pose analysis into one workflow:

  • Calculates exact BMI and tailors custom meal and workout plans.
  • MediaPipe Pose tracks 33 skeletal landmarks via WebCam.
  • Automated repetition counting based on joint flexion and extension.
  • Persistent MongoDB storage for returning users and session stats.

01

08

◆ Real-Time Pose Analysis (Computer Vision Engine)

The application uses MediaPipe Pose to detect 33 bodily landmarks from real-time camera input and evaluates joint angle geometry to power repetition counting and form feedback.

Biomechanics & Joint Angles

The angle θ between three connected landmark coordinates (A, B, C where B is the vertex) is calculated using the 2D arctangent formula:

θ = |atan2(Cy - By, Cx - Bx) - atan2(Ay - By, Ax - Bx)| * 180 / π

Key evaluated joints include Left Arm, Right Arm, Left Knee, and Right Knee.

Exercise Feedback Logic

  • Squats: Knee angle > 120° → "Squat deeper — break 90°"; < 60° → "Too deep — rise slightly"; 60°-120° → "Great squat depth!"
  • Push-ups: Arm angle < 50° → "Go lower — arms not deep enough"; > 178° → "Lock out arms fully at top".
  • Bicep Curls: Arm angle > 150° → "Curl the weight up more"; < 30° → "Perfect curl — now lower slowly".
  • Lunges: Front knee angle > 110° → "Lunge deeper — front knee at 90°".

◆ Personalized Fitness Plans & Recommendations

◆ About the Project

This project is a full-stack OTP-based authentication system designed to provide passwordless authentication using one-time passwords.

The system allows users to authenticate through either email or phone number, receive a six-digit OTP, verify the code, and access a protected dashboard after successful authentication. It protects against unauthorized access and provides a smooth, secure user experience.

◆ How It Works

01
User Request
User enters their email address or phone number (with country code) and selects the delivery mode.
02
Send OTP
Backend generates a 6-digit cryptographic OTP, hashes it with bcrypt (10 salt rounds), stores it with a 10-minute expiry, and dispatches via Brevo or Twilio.
03
Verify OTP
User enters the six-digit verification code. The system enforces a 60-second resend cooldown and validates submitted characters.
04
JWT Token Issuance
Upon successful bcrypt verification, the OTP record is purged, a user document is upserted, and a signed 7-day JWT token is returned to the client.
05
Protected Access
JWT is persisted client-side in LocalStorage. React router unlocks the authenticated Dashboard session and queries GET /api/auth/me.

◆ Security & Authentication Mechanisms

OTP Expiration & Rate Limiting

OTPs are stored with a strict 10-minute expiry time. In MongoDB, a TTL (Time-To-Live) index automatically purges expired records at the database level:

otpSchema.index({ expiresAt: 1 }, { expireAfterSeconds: 0 });

Endpoint /api/auth/send-otp is protected with express-rate-limit (max 10 requests per 15 mins per IP), with proxy trust enabled for Render.

Bcrypt Hashing & JWT Sessions

OTPs are never stored in plaintext. The backend creates a cryptographic salt (10 rounds) and stores the bcrypt hash:

const hashedOTP = await bcrypt.hash(otp, salt);

Upon verification, a JWT token signed with process.env.JWT_SECRET is issued with a 7-day expiration for stateless route authorization.

◆ Email & SMS Delivery Pipeline

The system intelligently routes OTPs depending on whether the user entered an email address or an international E.164 phone number:

EMAIL SERVICE HTTPS REST API

Nodemailer + Brevo HTTP API

Render free-tier instances restrict standard SMTP outbound traffic (ports 25, 465, 587). The implementation connects directly to Brevo's HTTP API (api.brevo.com/v3/smtp/email) over HTTPS port 443 with API key authentication, delivering custom HTML OTP templates reliably.

SMS SERVICE Twilio Telephony

Twilio Programmable SMS

For mobile authentications, the backend validates international format (^\+[1-9]\d{6,14}$) and dispatches via Twilio's official Node.js SDK (client.messages.create), delivering a 6-digit code with security warnings directly to the user's mobile device.

◆ About the Project

AI-Agent / Grounded SAM 2 is an advanced computer vision system that enables open-world object detection, segmentation and tracking using state-of-the-art foundation models.

It accepts arbitrary natural language text prompts (e.g. "person, car, dog") and performs zero-shot object detection using Grounding DINO, generates pixel-accurate masks with SAM 2, and tracks objects across video frames with persistent tracking IDs.

The system supports both high-resolution static images and custom videos, high-resolution inference using SAHI (Slicing Aided Hyper Inference), and exports all results as structured JSON.
